# TASK-006 — Public Frontend

## Objective

Provide a responsive frontend for external Pokémon browsing and details.

## Dependencies

- TASK-001
- TASK-002
- TASK-003

## In Scope

- catalog page
- pagination
- cards with required list attributes
- detail view
- loading/error/empty states
- responsive layout
- backend API integration

## Out of Scope

- local Pokémon management
- authentication UI
- elaborate visual design

## Acceptance Criteria

- [ ] Catalog works on desktop and mobile widths.
- [ ] Pagination works.
- [ ] Details can be opened.
- [ ] Required details are visible.
- [ ] Loading/error states are understandable.
- [ ] No avoidable console warnings.
- [ ] Build succeeds.

Keep state management local/simple unless complexity proves otherwise.
